# dbt Analytics

Self-contained local dbt project using DuckDB.

## Start here

```sh
cd ~/dev/github/dbt-analytics
dbt debug
dbt build
```

Entering the folder automatically activates the project Python environment and selects the project-local dbt profile through `direnv`.

See [SETUP.md](SETUP.md) for the complete personal setup guide, daily workflow, project layout, and explanation of every command.
